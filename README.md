## About The Project

CENDO is a website designed for discovering and managing house music events. The website showcases all events organized by CENDO, giving users a clear overview of upcoming parties and everything they need to know before attending.

Visitors can explore events, view detailed information such as line-ups and locations, and purchase tickets directly through the platform. In addition, the website provides useful information like frequently asked questions, house rules, and an overview of all artists who have previously performed at CENDO events.

The project also includes a custom-built CMS, allowing administrators to easily manage events, users, tickets, and locations. This makes it possible to keep the platform up-to-date and scalable as the number of events grows.

This project was developed as part of a school assignment, with a focus on usability, user experience, and full-stack development using modern web technologies.

## Getting Started


### Prerequisites
* npm
  ```sh
  npm install npm@latest -g
  ```

### Installation

_Underneath the instructions to install this website._

1. Clone the repo
   ```sh
   git clone https://github.com/ThijnGlas/TECH-1-groepsopdracht.git
   ```
2. Install NPM packages
   ```sh
   npm install
   ```
5. Start server
   ```sh
   npm start
   ```
